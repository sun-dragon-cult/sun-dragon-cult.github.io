This release adds a new layer of build-time content checks to the compendium data pipeline, and
fixes a handful of pre-existing content bugs those checks caught.

- `@RQID[...]` cross-references between spells, skills, and other content are now verified to
  actually resolve, HTML in descriptions is checked for unclosed or mismatched tags, other Foundry
  document links (journal entries, actors, etc.) are checked for leftover placeholder targets, and
  locally-referenced token/artwork files are verified to exist.
- These checks caught and fixed real issues already present in the compendium: unbalanced HTML
  tags in several bestiary, rune magic, skill, and homeland description entries; the
  Discorporation spell's "see also" link was a dead placeholder and now correctly links to the
  Discorporation rune magic entry; and Create Fissure's reference to the falling rules was also a
  dead placeholder, now citing the core rulebook (RQG p156) directly instead.
