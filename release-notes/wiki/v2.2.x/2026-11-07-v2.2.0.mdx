This release moves the wiki's content to the data format of RQG system 6.2.0, where passions, rune
types, armor types and materials, and combat maneuvers are stored the same way in every language.

:::warning Requires RQG system 6.2.0

Upgrade the system to 6.2.0 **before** you install this release. Older systems can't read the new
rune type format. Until you upgrade the system, stay on wiki 2.1.0, which works with system 6.0 to
6.2.

:::

## The Same Content in Every Language

The passions, runes, armor and weapons in this module used to store some fields as English text: the
passion, the rune's type, the armor's type and material, and the names of the weapon's combat
maneuvers. With system 6.2.0 those fields hold a key instead, which the system shows in the language
of your world. So with a translation of the system, such as the Spanish one, these fields on the
wiki's items show in that language too, and a combat maneuver gets its default damage type and rules
whatever the language.

Item names don't change. They stay as the module writes them, until an item is saved on its sheet,
which builds the name in the language of the world.

You don't need this release for worlds you have already upgraded: system 6.2.0 also converts the
older format when it loads items from wiki 2.1.0 or earlier. This release stores the new format
directly.

See the [RQG 6.2.0 release notes](https://sun-dragon-cult.github.io/release-notes/rqg-v6.2.0) for
how the system handles these fields.

## For Content Creators

- Runes store their type as `runeType: element`, and passions their key, like `passion: Loyalty`.
  Armor stores `armorType: Cuirass` and `material: HeavyLeather`, and combat maneuvers
  `name: Parry`. A value that isn't in the system's list, like Elf Bark, is stored as text.
- The module's copy of the system's labels now holds only the armor types, materials, passions and
  rune types that item names are built from. The build checks that each label matches the system's
  English text, so the names in the module match the names the system builds.
