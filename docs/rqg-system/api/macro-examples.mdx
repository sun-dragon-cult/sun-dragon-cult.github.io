Macros to copy and adapt. Create a new macro of type **Script** in Foundry and paste the code. See
[Rolls](/rqg-system/api/rolls) and [Character data](/rqg-system/api/character-data) for everything
the functions can do. The examples find items by their rqid, so they work in worlds using any
language. See [Pointing at actors and items](/rqg-system/api#pointing-at-actors-and-items).

## Roll Scan for the selected token

```js
await game.system.api.rolls.ability("i.skill.scan");
```

## Roll Scan for every selected token, without dialogs

Whispers the results to the GM.

```js
const api = game.system.api;
const lines = [];
for (const token of canvas.tokens.controlled) {
  const roll = await api.rolls.ability("i.skill.scan", { actor: token, skipDialog: true });
  const success = roll.successLevel <= api.rolls.SuccessLevel.Success;
  lines.push(`${token.name}: ${success ? "spotted it" : "saw nothing"}`);
}
ChatMessage.create({
  content: lines.join("<br>"),
  whisper: ChatMessage.getWhisperRecipients("GM"),
});
```

## POW×5 roll with a penalty

```js
await game.system.api.rolls.characteristic("power", {
  skipDialog: true,
  modifiers: [{ description: "Exhausted", value: -10 }],
});
```

## Who in the party knows Heal?

```js
const party = game.actors.filter((a) => a.hasPlayerOwner);
const lists = await Promise.all(party.map((a) => a.getCastableSpells()));
const healers = party.filter((a, i) => lists[i].some((s) => s.rqid === "i.spirit-magic.heal"));
ui.notifications.info(`Healers: ${healers.map((a) => a.name).join(", ") || "none"}`);
```

## Cast the selected token's first matrix spell

```js
const actor = canvas.tokens.controlled[0]?.actor;
const spell = (await actor?.getCastableSpells())?.find((s) => s.source === "matrix");
if (spell) await game.system.api.rolls.spiritMagic(spell);
```

## Attack two-handed with a short spear

```js
await game.system.api.rolls.attack("i.weapon.short-spear", { usage: "twoHand" });
```
