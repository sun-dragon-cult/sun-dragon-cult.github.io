Characters and their items are normal Foundry documents, so macros and modules read them from
`actor.system`, `actor.items` and `item.system`, the same way as for any other system. Read them
again when you need current values.

The fields of the character and of each item type (`skill`, `rune`, `passion`, `weapon`, `cult` and
so on) are described by JSON Schemas, one file per type, with field types and defaults. They are
generated from the system's data models:

- [Character](https://github.com/sun-dragon-cult/fvtt-system-rqg/blob/v6.1.1/src/data-model/json-schemas/generated/actor/character.schema.json)
- [Items](https://github.com/sun-dragon-cult/fvtt-system-rqg/tree/v6.1.1/src/data-model/json-schemas/generated/item)

Some `actor.system.attributes` values, like `max` hit points and magic points, `dexStrikeRank`,
`sizStrikeRank` and `damageBonus`, are calculated from the characteristics every time the character
changes. You can read them, but changing them has no lasting effect.

The rqid of any item is in `item.getFlag("rqg", "documentRqidFlags")?.id`, see
[Rqid](/rqg-system/api/rqid).

The rest of this page covers what the system works out from the rules, which is not stored on the
documents.

## Weapons

A weapon is an item with up to four ways of using it, `system.usage.oneHand`, `offHand`, `twoHand`
and `missile`. Each has stored values like `strikeRank`, `minStrength`, `minDexterity` and the
linked skill. The attack chance and whether the character is strong and quick enough come from the
skill, the weapon's effects and the rules, so ask the weapon:

```js
const spear = actor.items.find((i) => i.name === "Spear" && i.type === "weapon");
const info = spear.system.getUsageInfo("twoHand");
info.totalChance; // the linked skill's chance plus the weapon's effect modifiers
info.unusable; // true when the character is below the STR or DEX requirement
```

The result also has `skillItem`, `skillChance`, `weaponEffectModifier`, `underMinSTR` and
`underMinDEX`. The weapon has to belong to a character. Use [`rolls.attack`](/rqg-system/api/rolls)
to attack with it.

## Castable spells

`actor.getCastableSpells()` lists all spirit and rune magic the character can cast, their own spells
first. It follows the rules for spells from somewhere else than the character, so use it instead of
looking through `actor.items` when you need to know what the character can cast.

Each entry has `type` (`"spiritMagic"` or `"runeMagic"`), `name`, `points` and `source`, which says
where the spell comes from:

| `source`        | The spell is known by                                       |
| --------------- | ----------------------------------------------------------- |
| `"own"`         | The character                                               |
| `"allied"`      | The character's Allied Spirit, or the priest it's bonded to |
| `"boundSpirit"` | A spirit bound into one of the character's items            |
| `"matrix"`      | A spell matrix the character has equipped                   |

Spells from somewhere else than the character also have `sourceName`, the name of the spirit or the
matrix item. Spirit magic has `isVariable`, rune magic has `isOneUse` and the `cultId` and
`cultName` of the cult it's cast through.

Pass an entry to [`rolls.spiritMagic` or `rolls.runeMagic`](/rqg-system/api/rolls) to cast it.
