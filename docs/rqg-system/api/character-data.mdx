Characters and their items are normal Foundry documents, so macros and modules read them the way
they read any other Foundry data: from `actor.system`, `actor.items` and `item.system`. The system
has no separate functions for this. Values change when the character changes, so read them again
when you need current ones.

```js
const actor = canvas.tokens.controlled[0]?.actor;
```

## Skills, runes and passions

Each is an item on the character. Filter `actor.items` by `type`:

```js
const skills = actor.items.filter((i) => i.type === "skill");
for (const skill of skills) {
  console.log(skill.name, skill.system.chance, skill.system.category);
}
```

`type` is `"skill"`, `"rune"` or `"passion"`. All three have `system.chance`, and
`system.hasExperience` is true when the character has a pending experience check. The rqid of any
item is in `item.getFlag("rqg", "documentRqidFlags")?.id`, see [Rqid](/rqg-system/api/rqid).

## Castable spells

`actor.getCastableSpells()` lists all spirit and rune magic the character can cast, their own spells
first. It follows the rules for spells from somewhere else than the character, so use it instead of
looking through `actor.items` when you need to know what the character can cast.

Each entry has `type` (`"spiritMagic"` or `"runeMagic"`), `name`, `points` and `source`, which says
where the spell comes from:

| `source`        | The spell is known by                                       |
| --------------- | ----------------------------------------------------------- |
| `"own"`         | The character                                               |
| `"allied"`      | The character's Allied Spirit, or the priest it's bonded to |
| `"boundSpirit"` | A spirit bound into one of the character's items            |
| `"matrix"`      | A spell matrix the character has equipped                   |

Spells from somewhere else than the character also have `sourceName`, the name of the spirit or the
matrix item. Spirit magic has `isVariable`, rune magic has `isOneUse` and the `cultId` and
`cultName` of the cult it's cast through.

Pass an entry to [`rolls.spiritMagic` or `rolls.runeMagic`](/rqg-system/api/rolls) to cast it.

## Values stored on the character

Values that are stored on a character, rather than worked out by the rules, have no query function.
Read them from `actor.system`:

```js
const actor = canvas.tokens.controlled[0]?.actor;
actor.system.characteristics.power.value; // 15
actor.system.attributes.hitPoints; // { value: 12, max: 14 }
actor.system.attributes.magicPoints; // { value: 9, max: 15 }
actor.system.attributes.heroPoints; // 1
actor.system.background.reputation; // 15
```

Rune Points are stored on each cult:

```js
for (const cult of actor.items.filter((i) => i.type === "cult")) {
  console.log(cult.name, cult.system.runePoints); // Orlanth { value: 2, max: 3 }
}
```

Some values, like `max` hit points and magic points, `dexStrikeRank`, `sizStrikeRank` and
`damageBonus` under `actor.system.attributes`, are calculated from the characteristics every time
the character changes. You can read them, but changing them has no lasting effect.

To change a stored value, use Foundry's `update`, for example
`actor.update({ "system.attributes.magicPoints.value": 5 })`.
